## 项目是什么

**Hermes 的 Agent/配置/Skills + 适配 Hermes 的 Web 工作台 + U 盘便携外壳。**

目标：一次成功，多次复用；一张已验证能力卡片对应一项有证据、适用范围明确的方法。
Hermes 负责规划和工具执行；工作台负责输入、真实状态、审批与证据展示；外壳负责运行时、
目录迁移、服务和程序更新。不另建 DAG/工作流执行引擎，不承诺通用业务回滚。
打印机只是可选案例，首个试点使用测试文件整理。远程 API 优先，不集成本地模型 Runtime。
