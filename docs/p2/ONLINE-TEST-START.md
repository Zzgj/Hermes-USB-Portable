## 安装前

- 使用 Windows 10/11 x64，普通用户运行，不需要管理员权限。
- 核对 ZIP 的 SHA-256，然后将**整个目录**解压到一个独立的本地目录。不要从压缩软件内部启动，不要放进已有 Hermes 实例。
- 包内带有锁定版本的 Python、Node、uv、ripgrep，以及校验过的 PortableGit 自解压材料。它仍需要联网获取指定提交的公开项目/Hermes 源码，以及 Python/npm 依赖；不是仅能访问模型接口就够了。
- 安装会执行依赖自身的安装及构建脚本。当前不继承个人 npm/Git 配置、代理认证或模型密钥；如果网络需要公司认证代理，本候选不支持自动导入，失败时保留现场并反馈阶段名，勿发送凭据。
- 源码使用包内清单中的固定提交，不跟踪移动分支、不自动升级。尚未发布到 origin 的项目提交不能用于交付。

## 首次安装

1. 双击解压目录中的 **`Install-Online.bat`**。
2. 输入一个**尚不存在的绝对目录**，例如 `E:\Hermes-Test`。其父目录必须存在；不要先手动创建该目录，也不要选择已有便携实例。安装包目录和目标目录不得相互包含。
3. 看清网络与构建说明后，输入 `INSTALL`。不需要输入任何模型密钥。
4. 等待阶段 `runtime` → `source` → `dependencies-and-assets`。
5. 只有输出 `prepared-not-accepted` 才表示组装完成，**不表示实机验收通过**。依赖和 Dashboard 构建可能需要较长时间，请保持终端开启。

初始化使用独立的 `.hermes-online-*` 材料目录和新的目标目录，不写现有 Hermes home。安装失败时停止，不自动重试、不覆盖目标、不清锁、不自动删除现场。

## 打开及集中测试

- 组装完成后，从目标目录打开 **`P2-Workbench.bat`**，按该入口提示进入工作台。
- 先确认工作台可加载，再在设置中的原生入口区域检查 CLI 与 Dashboard；分别启动、交互、停止和重新检查。按钮成功或进程存在不能代替页面/终端实际可用。
- 新实例**没有你的模型配置**。本包不导入任何旧配置，不自动调用模型；模型配置及真实对话须在该新实例的已核实配置入口中由用户另行完成。不要在聊天回传 API key。
- 这不是完整 P2 产品验收清单；尚未完成的模型配置 UI、其余 P2 功能及 Windows 原生验收不能由安装成功代替。
- 本实验根不要运行默认安装器或自动升级来“修复”内核，默认初始化基线不同；不要搬动已组装目录后直接启动，跨路径恢复尚未验收。

## 失败和停止

- 安装失败：保留目标及其父目录下本次新建的 `.hermes-online-*`。查该材料目录的 `online-result.json`；若已进入组装，另保留目标中的 `logs/diagnostics/native-experiment-failure.json` 和中断标记。
- 只反馈失败阶段、错误类别及不含敏感数据的诊断；不要打包 `data/`、配置、认证文件或完整用户目录。
- 工作台启动后，通过它提供的显式停止入口收尾；若状态为 unknown 或锁仍保留，不全局结束 Python/Node，不手动删锁。保存现象并停止继续操作。
- 不自动删除 `.hermes-online-*`；确认进程树退出并完成验收前保留。该材料目录不是要上传到公共仓库的产物。
